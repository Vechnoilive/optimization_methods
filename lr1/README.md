# Лабораторная работа № 1. Закупка упаковки

Вариант 11.

## Запуск в Google Colab

[Открыть ноутбук в Colab](https://colab.research.google.com/github/Vechnoilive/optimization_methods/blob/main/lr1/lr1.ipynb) и выбрать **Среда выполнения → Выполнить всё**.
Первая ячейка устанавливает версии библиотек из `requirements.txt` в корне репозитория.
Если Colab запросит перезапуск сеанса после установки, перезапустите сеанс и выполните все ячейки снова.

## Запуск в Linux

Из корня репозитория в окружении Python 3.12.

```bash
python -m pip install -r requirements.txt jupyter nbconvert
jupyter nbconvert --to notebook --execute --stdout lr1/lr1.ipynb > lr1_executed.ipynb
```

## Данные и результаты

Спрос, лимиты поставщиков и тарифы получены небольшим случайным разбросом от шаблонов. Лимиты по тарифам заданы шаблоном. Ноутбук читает `data.json` или воссоздаёт его с `seed=10012`, если файла ещё нет.
Планы, таблицы сценариев, независимая проверка и лог HiGHS записываются в `lr1/results`.
В этом же ноутбуке есть задание со звёздочкой «Эластичный фильтр». Его файлы сохраняются в `results/star`.
