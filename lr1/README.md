# ЛР № 1. Закупка упаковки

Вариант 11. Нужно закрыть спрос на четыре вида упаковки и выбрать самый дешёвый план закупки у пяти поставщиков. У каждого есть общий лимит и отдельные квоты на закупку по оптовой цене.

[Открыть в Colab](https://colab.research.google.com/github/Vechnoilive/optimization_methods/blob/main/lr1/lr1.ipynb) · [Отчёт](LR1_V11_Zarechkin.pdf) · [Отчёт по звёздочке](Star1_LR1_Elastic_Filter.pdf)

В Colab выбери **Среда выполнения → Выполнить всё**. Первая ячейка устанавливает зависимости. Если Colab попросит перезапустить сеанс, запусти ячейки заново.

Данные лежат в `data.json`. Для каждой пары «поставщик и вид упаковки» заданы две цены и две квоты. К шаблону добавлен небольшой разброс цен, спроса и общих лимитов. Если файла нет, ноутбук создаст его с `seed=10012`. Планы, сценарии, проверки и лог HiGHS сохраняются в `results`.
Файлы задания со звёздочкой сохраняются в `results/star`.

## Локальный запуск

Из корня репозитория в Python 3.12.

```bash
python -m pip install -r requirements.txt jupyter nbconvert
jupyter nbconvert --to notebook --execute --stdout lr1/lr1.ipynb > lr1_executed.ipynb
```
