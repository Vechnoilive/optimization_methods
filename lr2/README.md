Вариант 11.

## Запуск в Google Colab

[Открыть ноутбук в Colab](https://colab.research.google.com/github/Vechnoilive/optimization_methods/blob/main/lr2/lr2.ipynb) и выбрать **Среда выполнения → Выполнить всё**.
Первая ячейка устанавливает версии библиотек из `requirements.txt` в корне репозитория.
Если Colab запросит перезапуск сеанса после установки, перезапустите сеанс и выполните все ячейки снова.

## Запуск в Linux

Из корня репозитория в окружении Python 3.12.

```bash
python -m pip install -r requirements.txt jupyter nbconvert
jupyter nbconvert --to notebook --execute --stdout lr2/lr2.ipynb > lr2_executed.ipynb
```

## Данные и результаты

Излишки, дефициты и дуги заданы шаблоном. Стоимости и ёмкости дуг получены небольшим случайным разбросом. Ноутбук читает `data.json` или воссоздаёт его с `seed=10012`, если файла ещё нет.
Планы, таблицы сценариев, независимая проверка и лог HiGHS записываются в `lr2/results`.
В этом же ноутбуке есть задание со звёздочкой «Двойственная модель». Его файлы сохраняются в `results/star`.
