# Лабораторная работа № 3. Почасовое включение генераторов

Вариант 11.

## Запуск в Google Colab

[Открыть ноутбук в Colab](https://colab.research.google.com/github/Vechnoilive/optimization_methods/blob/main/lr3/lr3.ipynb) и выбрать **Среда выполнения → Выполнить всё**.
Первая ячейка устанавливает версии библиотек из `requirements.txt` в корне репозитория.
Если Colab запросит перезапуск сеанса после установки, перезапустите сеанс и выполните все ячейки снова.

## Запуск в Linux

Из корня репозитория в окружении Python 3.12.

```bash
python -m pip install -r requirements.txt jupyter nbconvert
jupyter nbconvert --to notebook --execute --stdout lr3/lr3.ipynb > lr3_executed.ipynb
```

## Данные и результаты

Мощности заданы шаблоном. Тарифы, стоимость пуска и повторяющийся профиль спроса имеют небольшой случайный разброс. Базовый расчёт использует первые 12 часов. Ноутбук читает `data.json` или воссоздаёт его с `seed=10012`, если файла ещё нет.
Планы, таблицы сценариев, независимая проверка и лог HiGHS записываются в `lr3/results`.
