# ЛР № 3. Почасовое включение генераторов

Вариант 11. Есть четыре генератора и нагрузка на 12 часов. Подбираю мощность и время запуска каждого генератора так, чтобы покрыть спрос с минимальными затратами.

[Открыть в Colab](https://colab.research.google.com/github/Vechnoilive/optimization_methods/blob/main/lr3/lr3.ipynb) · [Отчёт](LR3_V11_Zarechkin.pdf)

В Colab выбери **Среда выполнения → Выполнить всё**. Первая ячейка устанавливает зависимости. Если Colab попросит перезапустить сеанс, запусти ячейки заново.

Данные лежат в `data.json`. Из полного профиля нагрузки для базового плана беру первые 12 часов. Дальше по тому же профилю проверяю, как время решения меняется с ростом горизонта. Если файла нет, ноутбук создаст его с `seed=10012`. Планы, сценарии, проверки и лог HiGHS сохраняются в `results`.

## Локальный запуск

Из корня репозитория в Python 3.12.

```bash
python -m pip install -r requirements.txt jupyter nbconvert
jupyter nbconvert --to notebook --execute --stdout lr3/lr3.ipynb > lr3_executed.ipynb
```
