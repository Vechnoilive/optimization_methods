# ЛР № 3. Формирование проектных команд

Вариант 14. Набираю три команды из 12 кандидатов. В каждой нужен руководитель, разработчик и аналитик. Некоторые пары не могут работать вместе.

[Открыть в Colab](https://colab.research.google.com/github/Vechnoilive/optimization_methods/blob/main/lr3/lr3.ipynb) · [Отчёт](LR3_V14_Zarechkin.pdf)

В Colab выбери **Среда выполнения → Выполнить всё**. Первая ячейка ставит зависимости. Если Colab попросит перезапустить сеанс, запусти ячейки заново.

Роли идут по кругу, затраты сгенерированы целыми. Несовместимые пары для первых 12 кандидатов заданы шаблоном. Полные данные нужны для замеров на большем масштабе. Данные лежат в `data.json`. Seed генерации — `10011`. В `results` лежат планы, сценарии, проверки и лог HiGHS контрольного прогона.

## Локальный запуск

Из корня репозитория в Python 3.12.

```bash
python -m pip install -r requirements.txt jupyter nbconvert
jupyter nbconvert --to notebook --execute --stdout lr3/lr3.ipynb > lr3_executed.ipynb
```
